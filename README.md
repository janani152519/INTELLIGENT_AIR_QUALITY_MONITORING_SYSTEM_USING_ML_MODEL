# 🌫️ AI-Powered Air Quality Prediction Dashboard

This project is a **machine learning–based interactive web application** built using **Streamlit**.  
It predicts the **Air Quality Index (AQI)** based on environmental factors and pollutant concentrations such as PM2.5, PM10, NO2, SO2, CO, population density, and industrial proximity.

The model classifies the air quality into:

- ✅ Good  
- ⚠️ Moderate  
- 🚫 Poor  
- ☠️ Hazardous  

---

## 📌 Purpose

Growing pollution levels affect human health and the environment.  
This system helps:

- Citizens check air quality instantly
- Govt agencies monitor areas
- Health-sensitive groups (kids, seniors, asthma patients, pregnant women) make safe decisions

---

## 🚀 Features

- 🎛️ User-friendly sliders to input pollutant levels  
- 🔮 Real-time AQI prediction using **Random Forest Classifier**
- 📊 Visual analytics including:
  - Feature importance graph
  - AQI category distribution chart
  - Scatter plot comparison with dataset
- 🛡️ Safety recommendations:
  - Kids
  - Pregnant women
  - Asthma patients
  - Senior citizens
  - Mask usage, exercise safety & outdoor timing
- 🙌 Clean and modern UI with dynamic AQI alerts

---

## 🧠 Machine Learning Model

| Element | Details |
|--------|---------|
| Algorithm | Random Forest Classifier |
| Dataset Size | (User Defined) Custom air pollution dataset |
| Training/Test Split | 82% train / 18% test |
| Output | AQI Category (Good/Moderate/Poor/Hazardous) |
| Accuracy | ~ 95.2|
